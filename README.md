# E-Commerce Sales SQL Analysis

This project uses SQL in Google BigQuery to analyze e-commerce sales data from the public `thelook_ecommerce` dataset.

## Tools Used
- Google BigQuery
- SQL
- GitHub

## Business Questions
1. What is the total completed revenue?
2. Which product categories generate the most revenue?
3. How does revenue trend by month?

## Key Insights
- Completed orders generated approximately $2.75M in revenue.
- Revenue varies by product category, showing which categories drive the most sales.
- Monthly revenue trends help identify sales performance over time.

## SQL Skills Demonstrated
- SELECT statements
- WHERE filters
- Aggregate functions
- GROUP BY
- ORDER BY
- JOINs
- Date formatting
